# Object Oriented

Object-oriented programming is a pattern for organizing code that's critical whether or not you plan to make use of inheritance.

Exercises are grouped by topic (`Classes`, `Encapsulation`, `Abstraction`, `Inheritance`, `Polymorphism`). Each folder has a `readme.md` with the assignment and a `Main.cs` with the solution.

## Requirements

- .NET SDK 8.0

## Build

```bash
dotnet build
```

## Run

Some exercises print output. Run them by name:

```bash
dotnet run -- multiple-objects
dotnet run -- class-variables
dotnet run -- dragons-fight
```
